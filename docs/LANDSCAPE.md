# Related projects and where ARBITRU fits

*Checked with a limited web search on 13 November 2026. Facts change quickly: re-check before announcing or depending on anything below.*

- **Ludii** (Java, academic, ludeme-based) — the closest in ambition: <https://ludii.games/>. Games are written in Java-backed class grammar.
- **Fairy-Stockfish** (C++, GPL-3.0) — chess-like variants with user-defined rules via `variants.ini`: <https://github.com/ianfab/Fairy-Stockfish>.
- **Rust, chess-only:** `shakmaty` (chess and variants), `monster-chess` (fairy-chess move generation), `konig`, `Stonkfish`, `Oxidation` (GPL).
- **Gap targeted:** one Rust engine and rule language across *board, card, dice, tile and puzzle* games (the whole chiuta.ro rule-atlas family), MIT-licensed, WASM-ready. We did not find a Rust equivalent in a limited search; please re-check before announcing.
